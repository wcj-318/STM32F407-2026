# H题两排灰度循迹与精准停车开发工程文档 V2.0

> 方案参考文档：本文描述五路停车和精准停车的后续设计，不代表当前固件已经实现。当前阶段是第四阶段速度PI，当前引脚、状态和测试入口以根目录 `00_当前工程总览_完整引脚与功能说明.md` 为准。

## 1 方案定位

硬件布局：

    前进方向 →

    五路灰度（第一排）
    辅助停车确认

    八路灰度（第二排）
    主循迹 + 起停线检测

    轮胎位置

    A点启停线

H题启停线长度约5cm，八路灰度总长度约9cm，不能使用11111111作为唯一停车条件。

------------------------------------------------------------------------

# 2 传感器分工

## 八路灰度（主）

功能：

-   黑线位置检测
-   PID循迹
-   起点定位
-   终点起停线检测

摆放：

启动时让黑线中心对准八路灰度中心。

------------------------------------------------------------------------

## 五路灰度（辅）

功能：

-   辅助判断回到A点
-   提高停车可靠性
-   防止普通黑线误判

不参与高速PID。

------------------------------------------------------------------------

# 3 八路循迹算法

权重：

    S1 S2 S3 S4 S5 S6 S7 S8

    -7 -5 -3 -1 +1 +3 +5 +7

计算Error：

    Error = Σ(状态×权重)/有效黑色数量

PID：

    左PWM = Base - PID
    右PWM = Base + PID

------------------------------------------------------------------------

# 4 防止左右摆动

加入中心死区：

    abs(Error)<=1

    Error=0

避免直线时频繁左右修正。

弯道：

    速度=基础速度-|Error|×降速系数

减少高速蛇形。

------------------------------------------------------------------------

# 5 起停线检测

停车线：

-   长度约5cm
-   宽度约1.8cm

八路可能出现：

    11100111
    11000111
    11100011
    00111100
    01111110

不能判断：

    11111111

------------------------------------------------------------------------

# 6 八路停车判断

统计：

    black_count
    left_count
    right_count

条件：

    black_count>=4

    并且

    left_count>=1

    right_count>=1

连续保持：

50ms以上。

------------------------------------------------------------------------

# 7 五路辅助确认

五路长度约7cm。

不要求：

    11111

采用：

    black_count>=3

辅助确认停车区域。

------------------------------------------------------------------------

------------------------------------------------------------------------

# 9 编码器辅助停车

检测停车线后：

不要立即停止。

流程：

    检测

    ↓

    低速运行

    ↓

    编码器累计距离

    ↓

    停止

减少惯性误差。
