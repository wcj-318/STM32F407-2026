# STM32F407VET6 核心板 V5.5 板载资源说明

> 基于板载原理图、引脚图整理。

## 1. MCU基本信息

  项目       参数
  ---------- ----------------
  MCU        STM32F407VET6
  内核       ARM Cortex-M4F
  主频       168MHz
  Flash      512KB
  SRAM       192KB
  工作电压   3.3V
  晶振       25MHz(HSE)
  下载方式   SWD

------------------------------------------------------------------------

## 2. 板载资源

  资源           引脚               是否可复用   说明
  -------------- ------------------ ------------ ---------------------
  用户按键KEY1   PA0                ✔            硬件消抖，推荐EXTI0
  蓝色LED        PB2                ✔            同时为BOOT1
  绿色LED        PC5                ✔            普通GPIO输出
  USB转TTL       PA9、PA10          △            USART1
  CMSIS-DAP      PA13、PA14、NRST   ✘            下载调试
  BOOT0          Boot0              ✘            启动模式
  25MHz晶振      PH0、PH1           ✘            HSE

------------------------------------------------------------------------

## 3. 电源

### 5V

-   USB Type-C输入
-   5V排针输入/输出
-   500mA保险丝保护

### 3.3V

-   **3.3V_STM32**：STM32及板载器件供电
-   **3.3V_OUT**：外部模块供电（独立LDO）

------------------------------------------------------------------------

## 4. 下载调试

SWD接口：

-   SWDIO → PA13
-   SWCLK → PA14
-   RESET → NRST

> PA13、PA14不建议复用。

------------------------------------------------------------------------

## 5. USB

板载USB连接CMSIS-DAP，而不是STM32 USB。

功能：

1.  CMSIS-DAP下载器
2.  USB转TTL串口

串口：

-   USART1 TX：PA9
-   USART1 RX：PA10

------------------------------------------------------------------------

## 6. LED

### 蓝色LED

-   PB2
-   同时为BOOT1

### 绿色LED

-   PC5

推荐： - 系统运行状态 - 心跳灯 - 错误提示

------------------------------------------------------------------------

## 7. 按键

KEY1：

-   PA0
-   板载硬件消抖
-   推荐EXTI0上升沿中断

------------------------------------------------------------------------

## 8. BOOT

-   BOOT0：启动模式
-   BOOT1：PB2

正常启动：

BOOT0=0，从Flash启动。

------------------------------------------------------------------------

## 9. 已占用引脚

  引脚    用途
  ------- ----------
  PA13    SWDIO
  PA14    SWCLK
  NRST    RESET
  PH0     HSE
  PH1     HSE
  BOOT0   启动模式

------------------------------------------------------------------------

## 10. 可复用引脚

  引脚        资源
  ----------- -----------
  PA0         KEY1
  PB2         LED+BOOT1
  PC5         LED
  PA9、PA10   USART1

------------------------------------------------------------------------

## 11. 常用外设复用

### USART

  外设     TX         RX
  -------- ---------- ----------
  USART1   PA9        PA10
  USART2   PA2        PA3
  USART3   PB10/PD8   PB11/PD9
  UART4    PA0        PA1
  UART5    PC12       PD2
  USART6   PC6        PC7

### SPI

  SPI    引脚
  ------ ----------------
  SPI1   PA5 PA6 PA7
  SPI2   PB13 PB14 PB15
  SPI3   PB3 PB4 PB5

### I2C

  I2C    引脚
  ------ -----------
  I2C1   PB6 PB7
  I2C2   PB10 PB11
  I2C3   PA8 PC9

### CAN

  CAN    引脚
  ------ -----------
  CAN1   PA11 PA12
  CAN2   PB12 PB13

### ADC

PA0~PA7、PB0~PB1、PC0\~PC5。

### PWM推荐

-   电机：PD12\~PD15（TIM4）
-   舵机：PA6 PA7
-   编码器：PB6\~PB9

------------------------------------------------------------------------
